Kuchlarni qo'shish

Mavzu haqida ma'lumot (10-sinf)

1. Kuch va uni qo'shish

Kuch — jismlarning bir-biriga ta'sirini ifodalovchi vektor kattalik: uning moduli (son qiymati), yo'nalishi va qo'yilish nuqtasi bor. SI birligi — nyuton (1 N = 1 kg·m/s²). Kuch dinamometr bilan o'lchanadi. Bir jismga bir necha kuch ta'sir qilsa, ularning umumiy ta'sirini beruvchi kuch teng ta'sir etuvchi kuch deyiladi va vektor yig'indi sifatida topiladi:

R⃗ = F⃗₁ + F⃗₂ + … + F⃗ₙ

2. Muvozanatlashgan kuchlar

Kuchlarning vektor yig'indisi nolga teng bo'lsa (R⃗ = 0; koordinata shaklida ΣFₓ = 0 va ΣF_y = 0), kuchlar muvozanatlashgan. Inersial sanoq sistemasida jism tinch turadi yoki tekis to'g'ri chiziqli harakat qiladi (Nyutonning 1-qonuni), a = 0.

Ikki kuch muvozanati: F₁ = F₂, yo'nalishlari qarama-qarshi, bitta to'g'ri chiziq bo'ylab. Uch kuch muvozanatida kuch vektorlaridan yasalgan uchburchak yopiq bo'ladi; ipga ikki tomondan osilgan yuk uchun Lami teoremasi: T₁/sin β = T₂/sin α = mg/sin(α + β).

Eslatma: ta'sir va aks ta'sir kuchlari (Nyutonning 3-qonuni, F⃗₁₂ = −F⃗₂₁) turli jismlarga qo'yiladi, shuning uchun ular muvozanatlashmaydi.

3. Muvozanatlashmagan kuchlar

R⃗ ≠ 0 bo'lsa, jism tezlanish oladi (Nyutonning 2-qonuni). Tezlanish teng ta'sir etuvchi kuch bilan bir tomonga yo'nalgan:

a⃗ = R⃗ / m,   v = v₀ + a·t,   x = x₀ + v₀·t + a·t²/2

Og'irlik kuchi: F = mg (g ≈ 9,8 m/s²). Sirpanish ishqalanish kuchi: F_ishq = μN. Gorizontal sirtda N = mg, shuning uchun F_ishq = μmg.

4. Ikki kuchni qo'shish

R = √(F₁² + F₂² + 2F₁F₂·cos α),   tg φ = F₂ sin α / (F₁ + F₂ cos α)

Har doim |F₁ − F₂| ≤ R ≤ F₁ + F₂. Grafik usullar: parallelogramm qoidasi (R — umumiy nuqtadan chiqqan diagonal) va uchburchak qoidasi (F⃗₂ ning boshi F⃗₁ ning oxiriga qo'yiladi, R⃗ birinchining boshidan ikkinchining oxiriga o'tadi).

5. Ko'p kuchni qo'shish — proyeksiyalar usuli

Fₓ = F·cos α,  F_y = F·sin α,  Rₓ = ΣFₓ,  R_y = ΣF_y,  R = √(Rₓ² + R_y²),  tg φ = R_y / Rₓ

6. Kuchning tashkil etuvchilari

Bitta kuchni ikki perpendikulyar yo'nalish bo'yicha ajratish (qo'shishga teskari amal). Gorizontga α burchak ostidagi F kuch uchun: Fₓ = F·cos α, F_y = F·sin α, tekshirish: √(Fₓ² + F_y²) = F.

Qiya tekislik (burchak α): mg ning tekislik bo'ylab tashkil etuvchisi F∥ = mg·sin α, tekislikka perpendikulyar tashkil etuvchisi F⊥ = mg·cos α; N = mg·cos α. Ishqalanishsiz a = g·sin α; ishqalanish bilan jism tg α > μ bo'lsa sirpanadi, a = g(sin α − μ cos α). Yuqoriga tekis tortish kuchi F = mg(sin α + μ cos α).
